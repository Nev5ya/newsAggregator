**MVP**-приложение, осуществляющее агрегацию и вывод новостей из разных источников.

Реализовано: 
- Frontend с помощью Bootstrap и шаблонизатора Blade.
- Аутентификация и авторизация, подключен модуль Socialite.
- CRUD админка для взаимодействия с ресурсами приложения.
- Парсинг новостей с помощью очередей и планировщика задач.
